# Humanize-ZH

中文写作人类化工具集，让 AI 生成的文本更有人味、更像真人写的。

## 包含技能

### humanize-zh-writing - 中文人类化写作助手

去除 AI 写作痕迹，让文章读起来更像真人写的。

**触发词：** 去 AI 味、去掉 AI 感、让文章更像人写的、太 AI 了、写得太机器了、帮我改得自然一点、去掉 AI 痕迹、人类化写作、humanize

**功能：**
- 改写模式：识别文体类型，按对应策略改写，去除 AI 痕迹
- 策略模式：为特定文体提供有人味的写作建议

**支持文体：**
- 叙事类（新闻报道、深度调查、人物特写）
- 评论类（时评、专栏、影评）
- 信息类（科普、知识拆解、技术文章）
- 经历类（游记、测评、生活随笔）
- 娱乐类（八卦资讯、综艺吐槽）
- 商业类（PR 稿、商业报道）
- 对话类（采访稿、问答、播客文字稿）

### writer-style-zh - 作家风格写作助手

模仿特定作家的写作风格进行改写或创作。

**触发词：** 王小波风格、王朔风格、马尔克斯风格、卡尔维诺风格、博尔赫斯风格、用王小波写、用王朔写、痞子风格、魔幻现实、元叙事、迷宫叙事

**支持作家：**

| 作家 | 风格本质 |
|------|----------|
| 王小波 | 理性内核，流氓外壳。用逻辑推进叙事，语气痞而反讽 |
| 王朔 | 北京痞子腔，解构一切。口语节奏，自我贬损 |
| 马尔克斯 | 魔幻现实主义。非线性时间，平静叙述荒诞 |
| 卡尔维诺 | 结构即内容。元叙事，轻盈语气，图像清晰 |
| 博尔赫斯 | 迷宫与镜像。伪学术语气，无限循环结构 |

## 使用示例

**去 AI 味：**
```
帮我把这篇文章去 AI 味：[粘贴文本]
这篇科普文写得太 AI 了，帮我改自然一点
```

**作家风格：**
```
用王小波风格写一段关于上班的文字
用马尔克斯风格改写这段话：[粘贴文本]
```

## 核心理念

去 AI 味不是加随机噪声，也不是堆砌口语词。本质是：**模拟该文体真人写作特有的不完美**。

AI 写作的通病：正确、完整、均匀、顺滑。每段等长，每段有主题句，逻辑无缝衔接，结尾给稳妥总结。

真人写作的特征：有态度、有痕迹、有呼吸、有温度，而且往往不完整。

**判断标准：** 改写完之后，能感受到有一个具体的人在写吗？有，就对了。
